# meshup
A simplified chat interface for mobile devices using Meshtastic!

## Introduction
Meshtastic is great. I like it but I'm still learning about it. But I wanted to make a mobile chat app that was simple and clean, that allowed a device to join the network without needing the user to get bogged-down in all of the technical aspects! 

MeshUp is a exactly that!

I feel that I could establish a small Meshtastic device and give it to my mum, and get her to install MeshUp without me needing to help.

Once the device is added via Bluetooth, the rest is just regular texting app.
